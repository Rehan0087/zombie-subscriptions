# Kiroween 2026 submission checklist

Deadline: **Friday 4 December 2026, 2:00 PM Pacific** (22:00 UTC). No extensions.

## Key dates
- [ ] Request 4,000 free Kiro credits by **Tue 1 Dec, 12:00 PM PT** (allow 48 business hours) – sooner is better.
- [ ] Redeem the credit code by **Fri 4 Dec**.
- [ ] Optional: Devpost Build Session, **Wed 11 Nov, 10:00 AM PT**.
- [ ] Start a draft submission on Devpost early and save often.

## Eligibility
- [ ] Registered on kiroween.devpost.com.
- [ ] Work started on or after 30 Oct 2026 (this repo: 2 Nov 2026). Any reused code disclosed in the README.
- [ ] Built **with Kiro**: tasks executed from the specs in Kiro, with hooks and steering in use. Insufficient Kiro use is a disqualification.

## Repository
- [ ] Public GitHub repo (not GitLab/Bitbucket).
- [ ] `LICENSE` detected by GitHub and shown in the About section.
- [ ] `.kiro/` at the root, committed, not in `.gitignore`.
- [ ] README has run instructions, live URL and video URL.

## Required submission fields
- [ ] Category: **Costume Contest**.
- [ ] Working app URL (GitHub Pages). No login needed, so no credentials required.
- [ ] Text description of features and functionality.
- [ ] Demo video: under 3 minutes, public on YouTube, shows the app running, no third-party trademarks or copyrighted music (use the invented sample merchants and the synthesized sounds).
- [ ] "How Kiro was used" write-up (specs, steering, hooks, PBT, MCP, powers, custom agents, which Kiro apps).

## Bonus prizes (optional)
- [ ] **Best Student Project:** every team member a student; LinkedIn, student email, year/degree, school.
- [ ] **Social Blitz:** a post that *starts with* `#KiroweenHackathon26`, written in your own words, saying your favourite thing about Kiro and how it changed your approach. Post during the Submission Period; add the URL.
- [ ] **Bonus Blog:** a public blog post about Kiro and this build that says it was written for the Kiroween 2026 hackathon; add the URL.
- [ ] Best Demo: automatic.
